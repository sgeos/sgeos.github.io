### The Definition of Primary

**Primacy is a property of the document, and this survey derives it from the identifier.** A record is a report primary when it is a NASA Technical Reports Server record or carries a digital object identifier under the 10.21236 prefix, which Crossref registers for Defense Technical Information Center reports.
