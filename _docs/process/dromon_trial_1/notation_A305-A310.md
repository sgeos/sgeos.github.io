# Notation baseline for A305 to A310

Built by opus from `_sources/equations/A305.toml` and `A310.toml` at c1b3b8a. Authors of A306 to A309 reuse
these meanings where a symbol recurs with the same sense, prefer an article's own symbol table where it has
one, and list each deviation in their review mail. Symbols keyed in both neighbours are marked.
